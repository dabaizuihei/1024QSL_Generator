## 故障排除

### 常见问题

1. **程序无法运行**
   - 确保下载了正确操作系统版本的二进制文件
   - Linux/macOS用户请检查文件执行权限

2. **提示"当前不是1024程序员节"**
   - 请确保在10月24日运行程序
   - 程序支持全球任意时区，只要当地时间是10月24日即可

3. **文件保存失败**
   - 检查程序所在目录的写入权限
   - 确保磁盘有足够空间

4. **字符显示异常**
   - 确保使用支持UTF-8编码的终端
   - Windows用户建议使用PowerShell或现代终端
